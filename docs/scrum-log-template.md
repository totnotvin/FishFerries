# Scrum Log Template

> **A note before you fill this in.** The assignment asks for 5 daily scrum
> logs and Trello (or similar) sprint-board screenshots as evidence of an
> actual team process. Those need to reflect a real standup history and a
> real board you set up — I've left this as a blank template rather than
> writing fabricated meeting notes, since inventing a fake collaboration
> history would misrepresent process that didn't happen. Fill in real
> dates, names, and notes from your own sprint; if this was largely a
> solo build, it's fine to note that and keep the log as a personal daily
> check-in instead of a multi-person standup.
>
> For the sprint-board screenshots: create a board (Trello, GitHub
> Projects, Jira, etc.), lay out the actual tasks from this build as
> columns/cards (e.g. To Do / In Progress / Done), and paste screenshots
> into your final documentation — that has to come from a board you
> actually made.
